# CLAUDE.md - Assets

Static assets: logos, icons, images, and design resources.

## Contents

- `logo.svg` - Project logo (vector)

## Editing Rules

- Prefer vector formats (SVG) for logos/icons
- Include multiple sizes if raster (1x, 2x, 3x)
- Use descriptive filenames
- Keep originals (e.g., Figma/Sketch files) in separate design repo if large

## Usage

Assets here are shared across platforms. Platform-specific assets live in:
- `android/app/src/main/res/`
- `ios/Vauchi/Assets.xcassets/`
