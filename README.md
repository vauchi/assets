# Vauchi Assets

Brand assets, logos, and visual resources for Vauchi.

## Contents

| File | Description |

## Usage

These assets are used across all Vauchi projects:

- Website
- iOS app
- Android app
- Documentation
- Marketing materials

## Brand Guidelines

### Logo

- Use the SVG version whenever possible
- Maintain aspect ratio
- Minimum clear space: logo height on all sides
- Don't modify colors or proportions

### Colors

Primary: `#2563eb` (Blue)
Secondary: `#1e40af` (Dark Blue)
Background: `#ffffff` (White)
Text: `#1f2937` (Dark Gray)
